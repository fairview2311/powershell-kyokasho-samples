# 第3章　コマンドレットとオブジェクトの読み方

本の第3章を終えた時点の「作業箱」です。本のコードの枠の上の「サンプルコード　ch03/…」は、このフォルダーのファイルを指します。このフォルダーには、それまでの章で作ったファイルもすべて入っています。

この章でできるようになること:

- このパソコンの状態（メモリを多く使っているアプリ、止まっている自動起動のサービス）を表で見られる

## この章での使い方

作業箱は、本と同じく `$HOME\MidoriTools`（例 `C:\Users\you\MidoriTools`）に置く前提です。コマンドは、特に断りがなければ Windows Terminal の PowerShell 7 のタブで実行します。.ps1・.psm1・.psd1 は、5.1 でも日本語が文字化けしないよう、BOM 付きの UTF-8 で保存してあります。

1. このフォルダーの中身を `$HOME\MidoriTools` にコピーします（同じ名前のファイルは上書きします）。

2. スクリプトを実行します。

   ```text
   cd $HOME\MidoriTools
   .\Get-PcInfo.ps1
   ```

## うまくいったかの確かめ方

- コンピューター名・ユーザー名と、2つの表が表示される

動作しないときは、本の第3章の「うまくいかないとき」を見てください。
