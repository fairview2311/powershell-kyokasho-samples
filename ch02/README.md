# 第2章　最初のスクリプトを実行する

本の第2章を終えた時点の「作業箱」です。本のコードの枠の上の「サンプルコード　ch02/…」は、このフォルダーのファイルを指します。このフォルダーには、それまでの章で作ったファイルもすべて入っています。

この章でできるようになること:

- 作業箱に最初のスクリプト hello.ps1 を作り、実行ポリシーを設定して実行できる
- hello.bat をダブルクリックして、hello.ps1 を実行できる

## この章での使い方

作業箱は、本と同じく `$HOME\MidoriTools`（例 `C:\Users\you\MidoriTools`）に置く前提です。コマンドは、特に断りがなければ Windows Terminal の PowerShell 7 のタブで実行します。.ps1・.psm1・.psd1 は、5.1 でも日本語が文字化けしないよう、BOM 付きの UTF-8 で保存してあります。

1. `$HOME\MidoriTools` フォルダーを作り、このフォルダーの中身をコピーします。

2. ダウンロードした ZIP から取り出したファイルは、インターネットから入手したファイルとしてブロックされています。本の第2章の section 06 のとおり、ブロックを解除します。

   ```text
   Get-ChildItem -Path $HOME\MidoriTools -Recurse -File | Unblock-File
   ```

3. スクリプトを実行します。

   ```text
   cd $HOME\MidoriTools
   .\hello.ps1
   ```

## うまくいったかの確かめ方

- 日本語のあいさつの行が、文字化けせずに表示される

動作しないときは、本の第2章の「うまくいかないとき」を見てください。
